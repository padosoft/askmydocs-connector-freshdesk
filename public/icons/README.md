# Logo Freshdesk

`freshdesk.svg` è un'interpretazione editoriale del marchio Freshdesk per la famiglia di connettori AskMyDocs. Riprende colore e simbolo del [sito ufficiale Freshdesk](https://www.freshworks.com/freshdesk/), il cui [asset SVG](https://www.freshworks.com/beta/icons/template-2026/freshdesk-logo-icon.svg) è stato recuperato l'8 ottobre 2026.

Il provider pubblica l'icona editoriale in `public/connectors/freshdesk.svg` dell'host; `docs/readme/logo.svg` conserva il logo originale per il README. Entrambi vengono serviti localmente.

Il marchio Freshdesk appartiene a Freshworks ed è usato per identificare l'integrazione; la licenza Apache-2.0 del codice non attribuisce diritti sul marchio.
