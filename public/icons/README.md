# Logo Freshdesk

`freshdesk.svg` è il logo presente sul [sito ufficiale Freshdesk](https://www.freshworks.com/freshdesk/), recuperato l'8 ottobre 2026 dall'[asset SVG di Freshworks](https://www.freshworks.com/beta/icons/template-2026/freshdesk-logo-icon.svg).

Il provider pubblica questo file in `public/connectors/freshdesk.svg` dell'host; `docs/readme/logo.svg` ne conserva una copia per il README. Il logo viene servito localmente e mantiene i colori originali.

Il marchio Freshdesk appartiene a Freshworks ed è usato per identificare l'integrazione; la licenza Apache-2.0 del codice non attribuisce diritti sul marchio.
